# SFL-Native Language Modelling

Public doctoral research proposal for an SFL-native architecture for meaning-state language modelling.

## Read the proposal

Open `index.html` locally or publish this repository with GitHub Pages. The proposal is designed as a fixed-map, section-by-section reader with keyboard navigation and deep links.

## Repository contents

- `index.html` — public proposal reader
- `assets/css/proposal.css` — accessible editorial colour system
- `assets/js/proposal-reader.js` — document-map and keyboard navigation
- `CITATION.cff` — citation metadata

## Public scope

This repository contains the public proposal only. It excludes private working documents, branding materials, and research-process records.
