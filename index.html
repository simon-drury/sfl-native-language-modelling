01 / 08Project summary

Doctoral research proposal

An SFL-Native Architecture for Meaning-State Language Modelling

A proposal for language models that represent, track, and evaluate meaning as structured choices across context, discourse semantics, lexicogrammar, and expression.

Premise

Contemporary language models are extraordinarily capable pattern learners, but their internal representations are not designed around an explicit theory of how meanings are made. This project asks whether a Systemic Functional Linguistics (SFL)-native architecture can make meaning states inspectable, controllable, and empirically evaluable.

Core proposition

Model language as a trajectory through a structured meaning space, rather than only as a sequence of next-token probabilities.

02 / 08Research context and rationale

Why meaning needs an explicit architecture

Transformer language models generate coherent text by learning rich statistical regularities. Yet the relationship between their internal states and functional linguistic categories—field, tenor, mode; ideational, interpersonal, and textual meanings—remains indirect.

SFL provides a stratified account of language as a social semiotic system. It offers a principled vocabulary for describing choices, relations, and realisations across linguistic levels. This makes it a promising foundation for models whose behaviour can be analysed in terms that matter to human communication.

Research gap

Current work commonly uses linguistic theories as post-hoc interpretive lenses. This proposal instead investigates whether the theory can shape the representational and operational core of a language-model architecture.

“Language is as it is because of what it has to do.”— Halliday
03 / 08Aim and research questions

From linguistic theory to computational test

The project develops and evaluates an architecture in which meaning-state representations mediate between contextual conditions and linguistic realisation.

  1. RQ1

    Representation

    How can SFL’s stratified systems and networks be represented as computationally tractable, dynamically updated meaning states?

  2. RQ2

    Generation and interpretation

    Can meaning-state constraints improve control, explanation, and revision in language generation and interpretation tasks?

  3. RQ3

    Multilingual realisation

    How can shared meaning-state descriptions support contrastive realisation across typologically distinct languages?

  4. RQ4

    Evaluation

    Which linguistic, human-centred, and task-based measures best test the explanatory and practical value of the architecture?

04 / 08Conceptual framework

A stratified meaning-state model

The proposed architecture treats language generation and analysis as movement between related strata, with explicit state representations at each level.

01
ContextField · tenor · mode
02
Discourse semanticsIdeational · interpersonal · textual organisation
03
LexicogrammarSystemic choices and grammatical realisation
04
ExpressionPhonology / graphology / token sequence

The central research object is the transformation between these states: how contextual configurations activate semantic options, how semantic selections constrain grammatical choices, and how outputs can be traced back through this trajectory.

05 / 08Existing research platform

From proposal to research programme

The project begins from a developing research platform for representing linguistic analyses, system networks, and meaning-oriented generation workflows. The doctoral work will formalise this platform as a reproducible experimental environment rather than treating it as a finished product.

Its role is methodological: to support the specification of meaning states, trace their evolution through a model pipeline, and compare alternative realisations under controlled conditions.

Principle

Software is an instrument for testing the theory—not evidence that the theory has already been proven.

06 / 08Research design and work plan

Iterative theory–prototype–evaluation cycles

Phase 1

Specification

Translate selected SFL systems into explicit schemas, determine granularity, and define observable state transitions.

Phase 2

Prototyping

Build small, inspectable components that encode or predict meaning states alongside text-level behaviour.

Phase 3

Evaluation

Compare baselines and meaning-state variants using controlled linguistic tasks, expert judgement, and task performance.

Phase 4

Revision

Use observed failures to refine theoretical mappings, representations, and evaluation protocols.

The design keeps theoretical commitments falsifiable: every representational choice must yield a testable prediction about analysis, generation, or model explanation.

07 / 08Multilingual realisation and evaluation

Testing whether the architecture earns its complexity

Linguistic fidelity

Assess whether annotated functional distinctions are represented consistently and whether predicted state trajectories correspond to expert analyses.

Controllability

Test whether targeted changes to a meaning state produce intended changes in generated language while preserving non-targeted meanings.

Cross-lingual robustness

Examine how shared semantic descriptions realise differently across languages without collapsing meaningful typological differences.

Explanatory value

Compare the clarity and usefulness of state-based accounts against token-only or post-hoc explanations.

Evaluation will combine corpus-grounded analyses, controlled generation tasks, human linguistic judgement, and error analysis. Multilingual work will be staged: the initial contribution is a principled framework and evaluation design, not an unsupported claim of universal coverage.
